# Contributing to Phoenix RoboCopy Pro

Thank you for your interest in contributing to **Phoenix RoboCopy Pro**!  
This project is built for Windows power users, developers, and sysadmins — and your contributions help it grow stronger.

---

## 🧩 Ways You Can Contribute

### 1. Submit Improvements
- UI/UX enhancements  
- Performance optimizations  
- Better Robocopy flag handling  
- New preset templates  
- Documentation improvements  

### 2. Report Issues
If you find a bug or unexpected behavior, open an Issue with:
- Steps to reproduce  
- Expected behavior  
- Actual behavior  
- Screenshots or logs (if possible)

### 3. Add New Features
Feature ideas are welcome!  
Open an Issue labeled **Feature Request** and describe:
- What the feature does  
- Why it’s useful  
- How it should work  

### 4. Create Pull Requests
Before submitting a PR:
1. Fork the repository  
2. Create a new branch  
3. Make your changes  
4. Test thoroughly  
5. Submit a PR with a clear description
